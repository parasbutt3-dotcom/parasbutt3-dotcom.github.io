Connected accounts

What each source actually gives you

Every row is what the API genuinely exposes — no scraped ghosts, no fabricated events.

Google
Identity, granted scopes, token health. With consent: security alerts from Gmail (subject + date only, never bodies), calendar events, Drive file names. App-grant inventory stays a manual link — Google has no consumer API for it, and GHOSTTRACE tells you so.
GitHub
Pushes, pull requests, issues, stars, releases. Public events need no token; add a personal access token to include your private activity. Each event lands with repo, action and timestamp.
ActivityWatch
Window focus, browser visits, AFK state straight from the watchers already running on your computers — pulled over their local API, nothing leaves your network.
Wazuh
Agent status and SIEM alerts from your own Wazuh manager. TLS verification is on by default and configurable via CA bundle.
Phone companion
Battery, network, OS, and — with your permission — location and calendar pushed by the Android/iOS companion. Also a USB inspector that reads a trusted iPhone over pymobiledevice3.
Google Takeout
The deep history APIs don't offer: full Location History, place visits, My Activity and YouTube watch history — import the ZIP once, dedup is automatic.

Architecture, not promises

Privacy is the data model

Encrypted at rest

OAuth tokens and secrets stored with Fernet; passwords hashed with bcrypt; device keys only ever as SHA-256 hashes.

Metadata only

Gmail ingestion reads subjects and dates of Google's own alert emails. Message bodies never enter the database.

Retention & erasure

Events age out on a schedule you set (90 days default). Deleting your account revokes tokens and cascades every event away.

Honest gaps

When an API doesn't exist, the capability report says so and links the manual check. No fabricated events, ever.

Session control

Every login is a revocable session with IP and device; TOTP two-factor with single-use recovery codes; API keys for automation.

Audit trail

Sign-ins, token refreshes, integrations and deletions land in an audit log you can read and export.

Quick start

Four commands to your own dashboard

MIT-licensed. Runs on your machine with SQLite by default, PostgreSQL via Docker when you want it.

# clone and start the stack
git clone https://github.com/YOUR_USERNAME/ghosttrace
cd ghosttrace && cp .env.example .env

docker compose up --build

# then open the dashboard and connect your sources
open http://localhost:3000

Stop trusting someone else's cloud with your history.
