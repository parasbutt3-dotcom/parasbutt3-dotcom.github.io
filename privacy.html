Privacy policy

Last updated: 12 November 2026

GHOSTTRACE is self-hosted software. There is no GHOSTTRACE company server, no GHOSTTRACE account system in the cloud, and no analytics on this website. Whoever runs an instance runs your data — in most cases, that is you on your own machine.

1. What an instance collects

Only what you explicitly connect, and only what each provider's API actually exposes:

SourceData collected
Google (OAuth)Name, email, profile photo (openid email profile). Optional, only with your consent: Gmail — subject lines and dates of Google's own security-alert emails only; message bodies are never stored; Calendar — event titles, times, locations; Drive — file names and modified times, no file contents.
GitHubYour public events (pushes, pull requests, issues, stars, releases). If you add a personal access token, events from your own private repositories.
ActivityWatchWindow titles, browser visits and AFK status already collected by ActivityWatch watchers on your computers, read over their local API.
WazuhAgent status and alert events from your own Wazuh manager.
Phone companion (Android/iOS)Battery level, network type, OS and app version, and — only with the operating-system permission you grant — device location and calendar events.
Google Takeout importWhatever you upload: location history, place visits, My Activity entries, YouTube watch history.
Manual eventsAnything you post to the events API with an API key.

2. How it is protected

  • Passwords hashed with bcrypt; OAuth tokens and secrets encrypted at rest with Fernet (AES-128-CBC + HMAC).
  • Access and refresh tokens are short-lived JWTs; every login creates a revocable session record; refresh tokens rotate on use and can be revoked.
  • Two-factor authentication (TOTP) with single-use recovery codes.
  • Device keys are stored only as SHA-256 hashes; API keys are stored only as SHA-256 hashes.
  • An audit log records sign-ins, token events, integration changes and deletions.
  • Rate limiting on authentication and ingestion endpoints; CORS allowlist; TLS expected in production deployments.

3. Retention and deletion

Collected events age out automatically on a configurable retention window (default 90 days). Deleting your account from Settings revokes connected OAuth tokens with the provider and permanently removes every event, integration, device and log row linked to it.

4. What never happens

  • No sale, rental or sharing of data with third parties.
  • No tracking pixels, cookies or analytics on this website.
  • No fabricated events: when an API cannot provide something, GHOSTTRACE records the gap honestly instead of inventing data.

5. If someone else runs your instance

When a family member, team or organisation hosts GHOSTTRACE for you, their deployment and configuration govern your data. Ask them about their retention window, hosting location and access controls — the operator can export or delete everything, which is exactly why the default deployment is your own machine.

6. Contact

Questions about this policy: open an issue on the project's source repository, or contact the instance operator.
